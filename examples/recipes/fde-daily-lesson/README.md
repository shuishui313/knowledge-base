# 每日 FDE 短课

## 解决什么

把每天 9:00 推送的那一课整理进 `notes/hk-fde/`，并让中英索引都能点到。课程顺序见 [docs/fde-syllabus.md](../../../docs/fde-syllabus.md)。

## 怎么用

1. 新建 `notes/hk-fde/FDE-NN-YYYY-MM-DD-主题简述.md`。`NN` 与 Day 相同，接索引最后一行加一。编号不复用。
2. 第一行是 `# 标题`，空一行后写元数据：`**FDE-07** · **2026-11-08** · Day 7 · **主题板块** 需求发现 · **难度** 入门`。
3. 正文顺序：`场景`、`类比`、`原理`、`FDE 视角`、`面试怎么问`、`一句话带走`、`自测`。推送里的「回顾」不入库，小标题不带 ①②③。
4. 自测两题：第 1 题是推送里的复述题；第 2 题换一类雇主（AI 原生 / 产品公司、大厂云与平台、咨询与系统集成、甲方企业内部）再问。答案收在 `<details><summary>参考答案</summary>`。
5. 文末一行系列导航：上一篇、下一篇（只链已存在的文件）、[回到索引](../../../notes/hk-fde/README.md)。同时给上一篇补上「下一篇」。
6. 在 [README.md](../../../notes/hk-fde/README.md) 和 [README.en.md](../../../notes/hk-fde/README.en.md) 的表各加一行。英文行链接后写 `(in Chinese)`。
7. 不编造面经、公司原话和数字；写法要像人写的。

## 要改哪

| 文件 | 改什么 |
|------|--------|
| `notes/hk-fde/FDE-NN-….md` | 新的一课 |
| 上一篇文末 | 接上「下一篇」 |
| `notes/hk-fde/README.md` / `README.en.md` | 各加一行 |
