# AI 算法笔记

## 解决什么

加一篇面试里常见的机器学习算法笔记，并让 `notes/ai-algorithms/` 的中英索引都能点到它。索引表要有适用场景列。

## 怎么用

1. 在 `notes/ai-algorithms/` 新建 `ALG-NN-中文名(English).md`。`NN` 是课序，两位数字。下一篇用索引最后一个编号加一。已分配的编号不复用、不重排。学习顺序写在该目录的两份索引里。还没写的篇不要先建文件。
2. 文首写编号、日期、分类、难度、面试频率。写法：`**ALG-01** · **2026-11-06** · **分类** 回归 · **难度** 入门 · **面试频率** 极高`。同一编号写进两份索引的 `编号` / `No.` 列。
3. 正文先写 `适用场景` 和 `不适用场景`，然后按这个顺序：`场景`、`概念`、`香港落地例子`、`小练习`、`自测`。自测两题。
4. 自测后用 `<details><summary>参考答案</summary>` 收起答案。不要用 details 做中英切换。
5. 例子用虚拟、公开可见的场景。不写任何机构的内部材料。
6. 文末可以预告下一篇的题目。不要链接还没写的文件。加上 [回到索引](../../../notes/ai-algorithms/README.md)。上一篇若写了指向文件的「下一篇」，改成指向新文件。
7. 相关 YouTube 可选。放在参考答案之后、系列导航之前，标题用 `延伸观看`。同一系列同一天最多 2 条。只收相对热门的解说、一节短课，或有见解的分享。普通的长课、泛泛的网课不收。没有合格的就省略这一节，不凑数。不写播放量。不编造链接。
8. 在 [README.md](../../../notes/ai-algorithms/README.md) 和 [README.en.md](../../../notes/ai-algorithms/README.en.md) 的表各加一行。列是编号、分类、难度、面试频率、适用场景、标题。英文那一行在链接后写 `(in Chinese)`。

对照这篇：[线性回归](../../../notes/ai-algorithms/ALG-01-线性回归(Linear-Regression).md)。

## 要改哪

| 文件 | 改什么 |
|------|--------|
| `notes/ai-algorithms/ALG-NN-….md` | 新笔记 |
| 上一篇文末 | 系列里指向文件的「下一篇」，如果上一篇有这一行 |
| `notes/ai-algorithms/README.md` | 中文索引加一行，含适用场景 |
| `notes/ai-algorithms/README.en.md` | 英文索引加一行，链到中文正文 |
