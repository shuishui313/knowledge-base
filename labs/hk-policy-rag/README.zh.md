# HK Policy RAG（中文说明）

基于香港入境处公开指引的问答服务。只用原文作答并标明出处；资料里没有的就拒答；按用户角色先过滤文件再检索。

```bash
pip install -r requirements.txt
python -m pytest -q        # 5 个测试通过
python -m eval.run         # hit@3 13/14，范围外问题拒答 6/6
uvicorn app.api:app        # POST /ask、GET /healthz
```

不需要 API key 也能跑；有 OpenAI 兼容的 key 时，模型只能根据检索到的段落回答，没有引用或引用不存在的段落就拒答。

## 评测（离线，仅 BM25，20 道手写题）

- 可回答的 14 题：正确页面在前 3 名 13 题（93%），误拒 0 题
- 范围外 6 题（最低工资、年假、公屋、驾照、薪俸税率、学生角色问 TechTAS）：全部拒答
- 唯一失败：用「How long does ... process a GEP application」问法时排到了别的计划页面，而且没被拦下。阈值是在同一批题上手调的，数字只作参考。

## 设计取舍

- 先按角色过滤再排序，看不到的页面连词频统计都不参与
- 混合检索：计划名称和金额靠 BM25，换说法靠向量（可选）
- 宁可拒答也不乱答：移民规定答错的代价比不答大
- 分块不跨标题，约 180 词，标题一起入索引
- 默认引用原句，方便直接贴进邮件

## 资料与授权

`data/corpus/` 是 2026-11-07 抓取的 10 个入境处页面快照，每个文件记录来源网址和日期。入境处允许非商业转载并注明出处。劳工处要求事先书面许可，所以没有收录。不构成法律意见。

## 局限与下一步

只支持英文；拒答门槛是字面匹配；模型与向量路径未接真实接口测试；角色由请求传入、没有鉴权。下一步：收集真实问题、加 reranker、加繁体中文页面、上线日志与每周抽检、定时重抓并提示变更。
