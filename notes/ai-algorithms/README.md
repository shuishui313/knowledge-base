# AI 算法

从易到难，讲常用、香港 FDE 招聘里用得上的机器学习算法。每篇约 5–8 分钟：招聘切入 → 适用/不适用场景 → 场景 → 概念 → 香港落地例子 → 面试怎么说 → 小练习 → 两道自测。自测后面有收起的参考答案，先做再打开。延伸观看可选：同一系列同一天最多 2 条 YouTube，只收相对热门的解说、一节短课，或有见解的分享；普通的长课、泛泛的网课不收；没有合格的就省略这一节；不写播放量。

## 学习顺序

已经写好的是 ALG-01 线性回归、ALG-02 逻辑回归、ALG-03 决策树、ALG-04 K 近邻、ALG-05 K-Means、ALG-06 随机森林。下面是计划中的顺序。这些篇还没有文件，所以这里不放链接：

- ALG-07 梯度提升 / XGBoost
- ALG-08 朴素贝叶斯
- ALG-09 SVM
- 然后：PCA，神经网络与反向传播，过拟合与正则化，CNN，Attention / Transformer

ALG-09 之后的编号，等写成笔记时按课序接在已分配编号后面。已分配的编号不复用、不重排。

## 收录约定

- 一篇算法一个 Markdown 文件。文件名从一开始就带编号：`ALG-NN-中文名(English).md`。`NN` 是课序，两位数字。新笔记用下一个编号。已分配的编号不复用、不重排
- 文首写编号、日期、分类、难度、面试频率。同一编号出现在本文件和 `README.en.md` 的 `编号` / `No.` 列。写法：`**ALG-01** · **2026-11-06** · **分类** 回归 · **难度** 入门 · **面试频率** 金融场景高；纯公式推导在 FDE 面经里少见`
- 正文先写招聘切入，再写适用场景和不适用场景，然后是场景、概念、香港落地例子、面试怎么说、小练习、两道自测。自测后用 `<details><summary>参考答案</summary>`。以香港 FDE 招聘要考的内容为主。雇主按香港 FDE 的四类来分：① AI 原生/产品公司（如语音 AI、LLM 平台）② 大厂云与平台（如 BytePlus、阿里云）③ 咨询与系统集成（如 Deloitte）④ 甲方企业内部 FDE（银行保险、地产、基金）。不必每篇都放四行对照表，真正有帮助时才用，每篇最多一张。公开面经只写核对得了的常见问法，并标明「公开面经里的常见问法」；不编造某家银行或保险公司的原话、候选人故事或逐字题。可以有短的「拓展补充」。「面试怎么说」：约 45–60 秒候选人可以说出口的英文，加一句中文提示，写明用客户习惯的语言（粤语或普通话）讲清楚，用英文把结论写下来。自测仍是两题，其中一题可以问面试官换成另一类雇主时答案怎么变。还没写的下一篇只预告题目，不建文件、不放链接
- 相关 YouTube 可选，放在参考答案之后、系列导航之前的 `延伸观看`。同一系列同一天最多 2 条。只收相对热门的解说、一节短课，或有见解的分享。普通的长课、泛泛的网课不收。没有合格的就省略这一节，不凑数。不写播放量
- 新增时放入文件，并在本文件和 `README.en.md` 的表里各加一行。表里要有适用场景列。步骤见 [ai-algorithm-note](../../examples/recipes/ai-algorithm-note/README.md)
