## 写法

- 一课一个文件：`FDE-NN-YYYY-MM-DD-主题简述.md`，`NN` 与 Day 相同。编号不复用。
- 顺序：场景 → 类比 → 原理（解决什么问题、怎么工作、会在哪里坏）→ FDE 视角 → 面试怎么问 → 一句话带走 → 自测两题，答案收在 `<details><summary>参考答案</summary>` 里。
- 先有问题再有答案；能类比后端 / 高并发经验的地方就类比。
- 雇主类型按香港真实在招的四类：AI 原生 / 产品公司、大厂云与平台、咨询与系统集成、甲方企业内部。自测第 2 题换一类雇主再问一次。
- 不编造面经、公司原话和数字。引用的事实要能查到出处。
- 新增一课时，在本表和 `README.en.md` 各加一行。步骤见 [fde-daily-lesson](../../examples/recipes/fde-daily-lesson/README.md)。
