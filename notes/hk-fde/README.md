<a id="conventions"></a>

## 收录约定

- 一篇短课一个 Markdown 文件，文件名以日期开头
- 每篇有稳定编号 `FDE-NN`（两位数字，与 Day 相同）。新短课用下一个编号。不改已有编号，不重命名已有文件
- 结构保持：文首写编号、日期、Day、主题板块、难度；正文五段；自测后给出参考答案
- 相关 YouTube 可选，放在参考答案之后、系列导航之前的 `延伸观看`。同一系列同一天最多 2 条。只收相对热门的解说、一节短课，或有见解的分享。普通的长课、泛泛的网课不收。没有合格的就省略这一节，不凑数。不写播放量
- 新增时放入文件，并在本文件和 `README.en.md` 的表里各加一行。步骤见 [fde-daily-lesson](../../examples/recipes/fde-daily-lesson/README.md)
