## Conventions

- One Markdown file per note, stored in this folder. Keep both the Chinese and English terms in the filename, as in `AI幻觉(Hallucination).md`.
- Follow-up notes on the same topic should start with the date so they sort, for example `2026-10-19-幻觉(Hallucination).md`.
- When you add a note, put the file here and add a row to this table and to `README.md`. Steps: [ai-glossary-note](../../examples/recipes/ai-glossary-note/README.md) (in Chinese).
