## 收录约定

- 每篇笔记一个 Markdown 文件，直接放在本目录（文件名保留中英术语，如 `AI幻觉(Hallucination).md`）
- 同一主题的后续笔记，建议文件名以日期开头，便于排序（如 `2026-10-19-幻觉(Hallucination).md`）
- 新增笔记时：放入文件，并在本文件和 `README.en.md` 的表里各加一行。步骤见 [ai-glossary-note](../../examples/recipes/ai-glossary-note/README.md)
