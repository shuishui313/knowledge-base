# 明确不做

正文是简体中文。后续编辑不要把这些又做回去。

记录日期：2026-11-05。不编造面经一条补于 2026-11-06。公开阅读站一条补于 2026-11-06。

## 不为个人使用去用 gsspai Organization

solo 学习库不放进 gsspai。仓库留在 shuishui313。见 [decisions.md](decisions.md)。

## 不用 details 做中英文切换

不把两种语言折进同一个 `<details>` 语言标签。双语只走 `README.md` 与 `README.en.md` 的顶栏链接。

## 不编造面经

不写虚构的候选人故事，不编某家银行或保险公司的逐字面试题或引语，也不把公开记录里没有的题目写进那一篇。公开面经只写核对得了的常见问法，并标明「公开面经里的常见问法」。还没写的算法笔记不建文件、不放链接。

## 学习助手不代发求职冷邮件，也不代投

学习助手不写、不发求职冷邮件，不代投简历，不做代理求职申请。

已采纳的做法见 [decisions.md](decisions.md)。

## 公开阅读站不要加回去的东西（2026-11-06）

- 首页不要「最近更新」模块
- 不要学习进度显示或进度环
- 不要用「前线课」做站点名；站点名就是 Knowledge Base
- 不要给首页大标题做入场位移动画（字母会横向闪）
- 不要在芯片或目录卡片上展示发布日期
- 不要为了网页去改写 `notes/` 里的课文正文
